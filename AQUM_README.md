## 🌟 О проекте

**AQUM** — это комплексная экосистема для онлайн-образования, которая объединяет:

- 💬 **Мессенджер** (как Telegram) — личные и групповые чаты, звонки, стиль
- 📱 **Социальную ленту** (как Threads) — посты, комментарии, лайки
- 🎓 **Онлайн-школу** — курсы, уроки, задания, оплата

### Цели платформы:

✅ Быстрый матчинг «ученик ↔ преподаватель»  
✅ Проведение уроков (1:1 и групповых) с заданиями и оплатой  
✅ Комьюнити (посты, комментарии, лайки, сторис)  
✅ Прозрачная статистика и рейтинг

## 🚀 Установка

### Требования:

- PHP 7.4 или выше
- MySQL 8.0 или выше
- Apache/Nginx с mod_rewrite
- Расширения PHP: PDO, PDO_MySQL, mbstring, json

### Шаг 1: Клонирование проекта

```bash
cd /workspace
# Файлы уже на месте
```

### Шаг 2: Создание базы данных

#### Вариант A: Автоматическая установка (рекомендуется)

```bash
php setup_aqum.php
```

Скрипт автоматически:
- Удалит старые БД (waybels_db, wibs, aqum_db)
- Создаст новую БД `aqum_db`
- Выполнит все миграции
- Добавит тестовые данные
- Покажет статистику

#### Вариант B: Ручная установка

```bash
# Войдите в MySQL
mysql -u root -p

# Выполните:
source /workspace/database_aqum.sql
```

### Шаг 3: Проверка конфигурации

Файлы уже настроены:
- `config_aqum.php` - конфигурация приложения
- `db_aqum.php` - подключение к БД
- `helpers_aqum.php` - вспомогательные функции

### Шаг 4: Создание директорий

```bash
mkdir -p uploads/{avatars,documents,media}
mkdir -p logs
chmod -R 755 uploads logs
```

### Шаг 5: Запуск

#### Встроенный сервер PHP (для разработки):

```bash
php -S localhost:8000
```

#### Apache/Nginx:

Настройте виртуальный хост на папку `/workspace`

### Шаг 6: Открыть в браузере

```
http://localhost:8000/auth_aqum.php
```

## 🗄️ База данных

### Таблицы (19 штук):

#### Пользователи и профили:
1. **users** - Все пользователи (ученики, учителя, админы)
2. **teacher_profiles** - Профили преподавателей
3. **teacher_documents** - Документы для верификации
4. **settings** - Настройки пользователей

#### Социальная сеть:
5. **posts** - Посты преподавателей
6. **post_likes** - Лайки постов
7. **post_comments** - Комментарии к постам
8. **user_interactions** - Подписки и блокировки

#### Сообщения:
9. **channels** - Чаты (личные и групповые)
10. **channel_members** - Участники чатов
11. **messages** - Сообщения
12. **message_reads** - Прочитанные сообщения
13. **stories** - Сторис (только в разделе "Сообщения")
14. **story_views** - Просмотры сторис

#### Обучение:
15. **lessons** - Уроки
16. **lesson_orders** - Заказы уроков (для метрик)
17. **assignments** - Домашние задания
18. **progress** - Прогресс студентов

#### Платежи:
19. **transactions** - Транзакции
20. **teacher_balances** - Балансы учителей

#### Дополнительные:
21. **reviews** - Отзывы о преподавателях
22. **favorites** - Избранные преподаватели
23. **notifications** - Уведомления
24. **onboarding_tasks** - Задачи онбординга
25. **ip_guard** - Антифрод (логи IP)
26. **subjects** - Справочник предметов

### Метрики профиля преподавателя:

```sql
-- Количество заказов (orders_count)
SELECT COUNT(*) 
FROM lesson_orders 
WHERE teacher_id = ? AND status IN ('paid','confirmed','completed');

-- Количество уникальных учеников (students_count)
SELECT COUNT(DISTINCT student_id) 
FROM lesson_orders 
WHERE teacher_id = ? AND status IN ('paid','confirmed','completed');

-- Средний рейтинг (показывается после 10 уроков)
SELECT AVG(rating) 
FROM reviews 
WHERE teacher_id = ?;
```

## 📊 Ключевые бизнес-правила

### Видимость преподавателя:

Преподаватель показывается в поиске/рекомендациях, если:
- `is_teacher = 1`
- `is_verified_teacher = 1`
- `status = 'approved'` в `teacher_profiles`
- `last_seen_at` ≤ 48 часов назад

### Рейтинг:

- Показывается только после **10+ завершенных уроков**
- Рассчитывается из таблицы `reviews`

### Сторис:

- Показываются **ТОЛЬКО** в разделе `/messages`
- Срок жизни: 24 часа
- Автоматически удаляются после истечения

### Антифрод:

- Максимум **5 аккаунтов** с одного IP
- **5 попыток** входа, затем блокировка на 15 минут

## 🤝 Разработка

### Добавление новой страницы:

```php
<?php
// 1. Подключаем конфигурацию
require_once 'config_aqum.php';
require_once 'db_aqum.php';
require_once 'helpers_aqum.php';

// 2. Проверяем авторизацию
session_start();
requireAuth();

// 3. Получаем данные пользователя
$user_id = $_SESSION['user_id'];
$user = getUserById($user_id);

// 4. Обновляем last_seen
updateUserLastSeen($user_id);

// 5. Ваша логика...

// 6. Подключаем layout
include 'includes/header.php';
include 'includes/sidebar.php';
?>

<!-- Ваш HTML -->

<?php include 'includes/footer.php'; ?>
```

### API эндпоинты:

Все API эндпоинты возвращают JSON:

```php
jsonSuccess('Успешно', ['data' => $result]);
// или

```
