# 📚 Описание проекта WayBels

## 🎯 Что это за проект?

**WayBels** — это платформа для поиска и выбора репетиторов (онлайн-школа репетиторства). Проект позволяет:

### Для учеников (студентов):
- 🔍 **Поиск репетиторов** по различным предметам и направлениям
- 🎯 **Фильтрация** по интересам (языки, программирование, дизайн, маркетинг, математика, наука, музыка и др.)
- ⭐ **Рейтинговая система** — просмотр рейтинга и отзывов репетиторов
- ❤️ **Избранное** — сохранение понравившихся репетиторов
- 💬 **Система сообщений** — общение с репетиторами
- 📺 **Видео-презентации** — просмотр видео от репетиторов
- 📝 **Посты и материалы** — просмотр публикаций от репетиторов
- 👤 **Личный профиль** — управление своими данными

### Для репетиторов:
- 📋 **Подача заявки** на регистрацию в качестве репетитора
- 🎥 **Видео-презентация** — возможность добавить видео о себе
- 📊 **Статистика** — отслеживание количества уроков, рейтинга
- 📝 **Публикация материалов** — создание постов для привлечения учеников
- 💰 **Указание цены** за урок
- 📈 **Профиль с опытом** — указание лет опыта и описания

## 🏗️ Архитектура проекта

### Технологический стек:
- **Backend:** PHP 7.4+ (чистый PHP, без фреймворков)
- **База данных:** MySQL 5.7+ (InnoDB, UTF8MB4)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Дизайн:** Адаптивный (Desktop + Mobile), Glass morphism

### Структура базы данных:

1. **users** — Пользователи системы
   - Ученики (role='user')
   - Репетиторы (role='teacher')
   - Администраторы (role='admin')
   - Поддержка OAuth (Google, Apple)
   - Интересы пользователей

2. **teacher_profiles** — Профили репетиторов
   - Предмет преподавания
   - Описание и опыт
   - Цена за урок
   - Видео-презентация
   - Рейтинг и статистика
   - Статус модерации

3. **posts** — Посты от репетиторов
   - Заголовок и контент
   - Медиа (изображения, видео)
   - Статистика (лайки, просмотры)

4. **favorites** — Избранные репетиторы
   - Связь ученик ↔ репетитор

5. **chats** — Чаты между пользователями
   - Создание чатов между двумя пользователями

6. **messages** — Сообщения в чатах
   - Текст сообщений
   - Статус прочтения

7. **teacher_applications** — Заявки на репетиторство
   - Форма подачи заявки
   - Модерация администратором

## 🔐 Безопасность

- ✅ **CSRF защита** всех форм
- ✅ **XSS защита** через экранирование HTML
- ✅ **SQL Injection защита** через Prepared Statements
- ✅ **Хеширование паролей** (BCrypt)
- ✅ **Безопасные сессии** (HttpOnly, SameSite)
- ✅ **Валидация данных** на сервере и клиенте

## 📱 Адаптивность

- **Desktop (>968px):** Боковое меню слева
- **Mobile (<768px):** Нижнее меню с glass effect
- **Tablet (768-968px):** Адаптивная верстка

## 🎨 Дизайн

- **Цветовая схема:** Фиолетовый (#7F2CDF) — фирменный цвет
- **Шрифт:** Inter (Google Fonts)
- **Особенности:** Современный UI, плавные анимации, градиенты

## 🚀 Основные страницы

1. **index.php / auth.php** — Вход и регистрация с квизом интересов
2. **dashboard.php** — Главная лента репетиторов с поиском и фильтрами
3. **teacher.php** — Детальная страница репетитора
4. **profile.php** — Профиль пользователя
5. **messages.php** — Список чатов
6. **favorites.php** — Избранные репетиторы
7. **apply_teacher.php** — Заявка на репетиторство

## 🔧 Что нужно сделать для запуска

1. **Настроить базу данных:**
   ```bash
   mysql -u root -p < setup_database.sql
   ```
   Или через phpMyAdmin импортировать `setup_database.sql`

2. **Проверить подключение:**
   - Открыть `check_db.php` в браузере
   - Должно показать список таблиц и пользователей

3. **Запустить проект:**
   - Настроить веб-сервер (Apache/Nginx)
   - Открыть `index.php` в браузере
