## 🔄 КАК РАБОТАЕТ РЕГИСТРАЦИЯ

### Шаг 1: Основные данные
```
POST register_step1 →
  Сохраняем в $_SESSION['registration_data'] →
  $_SESSION['registration_step'] = 'age' →
  header('Location: auth.php'); exit; →
  Страница перезагружается →
  $currentStep = 'age' →
  Показываем форму Шаг 2
```

### Шаг 2: Возраст
```
POST register_step2 →
  Добавляем age в $_SESSION['registration_data'] →
  $_SESSION['registration_step'] = 'interests' →
  header('Location: auth.php'); exit; →
  Страница перезагружается →
  $currentStep = 'interests' →
  Показываем форму Шаг 3
```

### Шаг 3: Интересы
```
POST register_step3 →
  Создаем пользователя INSERT INTO users →
  Логиним пользователя →
  Очищаем сессии регистрации →
  header('Location: feed.php'); exit; →
  Открывается feed.php
```

**КРИТИЧЕСКИ ВАЖНО:** После каждого шага должен быть `header('Location: ...'); exit;` иначе страница не обновится!

## 📁 СТРУКТУРА ФАЙЛОВ

### auth.php
```php
// 1. Обработка POST
if ($_POST) {
    // логика
    $_SESSION['registration_step'] = 'age';
    header('Location: auth.php');
    exit;  // ВАЖНО!
}

// 2. Обновление $currentStep
$currentStep = $_SESSION['registration_step'] ?? null;

// 3. HTML с проверкой $currentStep
if ($currentStep === 'age') { ... }
```

### Проблема 1: "Не переходит на второй этап"
**Решение:** Добавили редирект после сохранения шага
