# 🚀 УСТАНОВКА AQUM

## Что изменилось?

### 🎨 Новый дизайн и функции:
- **Feed в стиле Threads/Instagram** - персональная лента с постами
- **Система заданий** - репетиторы могут давать задания ученикам
- **Username как URL** - профили доступны по @username
- **Темная тема** - автоматическое переключение авто/светлая/темная
- **Обновленное меню** - только лого, без текста
- **Настройки** - отдельная страница с управлением аккаунтом

## 📦 Установка базы данных

### Способ 1: Через браузер (рекомендуется)
1. Откройте в браузере: `http://ваш-домен/install_db.php`
2. Дождитесь завершения установки
3. Удалите файл `install_db.php` (безопасность)

### Способ 2: Через SQL
```bash
mysql -u root -p < RESET_DATABASE.sql
```

### Способ 3: Обновление существующей БД
```bash
mysql -u root -p aqum_db < UPDATE_DATABASE.sql
```

## 🗄️ Новая структура БД

### Обновления таблицы `users`:
- ✅ `username` - уникальный username (обязательно)
- ✅ `theme` - тема оформления (auto/light/dark)

### Новые таблицы:
- ✅ `assignments` - задания от репетиторов
- ✅ `stories` - истории пользователей

## 📱 Новые страницы

### 1. feed.php
- Персональная лента постов
- Задания от репетиторов
- Модальное окно выбора интересов

### 2. profile.php?user=username

### 3. settings.php
- Выбор темы оформления

- Выход из аккаунта

## 🎨 Темы

Система автоматически определяет тему устройства.
Переключение: **Меню → Кнопка темы**

Темы сохраняются в localStorage:
- `auto` - по системе
- `light` - светлая
- `dark` - темная

## 🚨 После установки

1. Проверьте `config.php`:
```php
define('DB_NAME', 'aqum_db');
define('APP_NAME', 'aqum');
define('DASHBOARD_URL', 'feed.php');
```

2. Убедитесь что тестовые пользователи имеют username:
```sql
SELECT id, name, username FROM users;
```

3. Проверьте работу тем:
- Откройте любую страницу
- Нажмите на кнопку темы в меню
- Тема должна меняться: Авто → Светлая → Темная

## 🎉 Готово!

Откройте `auth.php` и войдите с тестовым аккаунтом!
