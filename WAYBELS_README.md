# 🎓 WayBels - Платформа для репетиторов

Современная платформа для поиска и выбора репетиторов с интуитивным интерфейсом и богатым функционалом.

## 🚀 Возможности

### Для учеников:
- ✅ Поиск репетиторов по предметам
- ✅ Фильтрация по интересам
- ✅ Просмотр детальной информации (видео, опыт, рейтинг)
- ✅ Избранное (лайки репетиторов)
- ✅ Система сообщений
- ✅ Личный профиль

### Для репетиторов:
- ✅ Подача заявки на репетиторство
- ✅ Создание профиля с видео-презентацией
- ✅ Публикация материалов и постов
- ✅ Статистика (уроки, рейтинг)

### Технологии:
- ✅ PHP 7.4+
- ✅ MySQL 5.7+
- ✅ Адаптивный дизайн (Desktop + Mobile)
- ✅ Glass morphism для мобильного меню
- ✅ AJAX для динамических действий
- ✅ Современный UI в фирменных цветах

## 🗄️ База данных

### Таблицы:

1. **users** - Пользователи (ученики, репетиторы, админы)
2. **teacher_profiles** - Профили репетиторов
3. **posts** - Посты и материалы от репетиторов
4. **favorites** - Избранные репетиторы
5. **chats** - Чаты между пользователями
6. **messages** - Сообщения в чатах
7. **teacher_applications** - Заявки на репетиторство

## 🛠 Установка

### 1. Импорт базы данных

```bash
mysql -u root -p
```

```sql
source /workspace/database_waybels.sql
```

Или через phpMyAdmin:
1. Создайте базу `waybels_db`
2. Импортируйте `database_waybels.sql`

### 2. Настройка подключения

Файл `db.php` уже настроен:
```php
$host = "localhost";
$dbname = "waybels_db";
$username = "root";
$password = "WayBels2553030App!";
```

### 3. Создание папок для загрузок

```bash
mkdir -p img/avatars
chmod 755 img/avatars
```

### 4. Запуск

```bash
php -S localhost:8000
```

Откройте: `http://localhost:8000`

## ✨ Основной функционал

### 1. Лента репетиторов (`dashboard.php`)
- Карточки с информацией
- Поиск по предмету/имени
- Сортировка (рейтинг, уроки, новые)
- Фильтр по интересам пользователя
- Добавление в избранное (AJAX)

### 2. Страница репетитора (`teacher.php`)
- Видео-презентация (YouTube embed)
- Полная информация
- Рейтинг и статистика
- Описание до 500 символов
- Посты и материалы
- Кнопка "Написать"
- Добавление в избранное

### 3. Профиль (`profile.php`)
- Загрузка аватара
- Редактирование данных
- Смена пароля
- Кнопка "Стать репетитором"

### 4. Заявка на репетитора (`apply_teacher.php`)
- Форма с валидацией
- Предмет, описание (100-500 символов)
- Опыт, образование, сертификаты
- Ссылка на видео
- Статусы: pending, approved, rejected

### 5. Сообщения (`messages.php`)
- Список чатов
- Последнее сообщение
- Время (относительное)
- Переход в чат

### 6. Избранное (`favorites.php`)
- Список лайкнутых репетиторов
- Удаление из избранного

### Добавление новой страницы:
1. Создать PHP файл
2. Подключить `db.php`, `helpers.php`

4. Подключить `includes/sidebar.php`
5. Подключить `includes/bottom_nav.php`
6. Добавить стили
