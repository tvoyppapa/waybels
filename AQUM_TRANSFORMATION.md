### ✅ 2. База данных

Создана полная новая структура БД: **`database_aqum.sql`**

#### Новые таблицы:

**Контент и лента:**
- `posts` - посты от репетиторов (текст, фото, видео)
- `post_likes` - лайки
- `post_comments` - комментарии с поддержкой ответов
- `post_views` - аналитика просмотров

**Истории (Stories):**
- `stories` - истории на 24 часа
- `story_views` - просмотры историй

**Каналы и группы:**
- `channels` - каналы репетиторов
- `channel_subscribers` - подписчики
- `groups` - учебные группы
- `group_members` - участники групп

**Уроки и задания:**
- `lessons` - расписание уроков
- `assignments` - домашние задания
- `student_progress` - прогресс студентов

**Сообщения:**
- `chats` - чаты (личные, групповые, каналы)
- `chat_participants` - участники
- `messages` - сообщения с медиа

**Рекомендации:**
- `user_interactions` - взаимодействия для алгоритма
- `favorites` - избранные репетиторы

**Геймификация:**
- `achievements` - достижения (бейджи)
- `user_achievements` - достижения пользователей
- `user_experience` - уровни и опыт

#### Обновленные таблицы:

**`users`** - добавлены поля:
- `nickname` - никнейм пользователя
- `bio` - биография
- `last_seen_at` - время последней активности (для фильтрации)

**`teacher_profiles`** - добавлены поля:
- `short_description` - короткое описание (30-90 символов)
- `total_students` - количество учеников
- `languages` - языки преподавания
- `certifications` - сертификаты

### ✅ 3. Универсальная система навигации

Создана модульная система меню, которая легко переиспользуется.

#### Компоненты:

**`includes/sidebar.php`** (Desktop):
- Боковое меню слева
- Поддержка компактного режима (`$compact = true`)
- Автоопределение активной страницы
- Новая навигация: Лента → Поиск → Сообщения → Профиль

**`includes/bottom_nav.php`** (Mobile):
- Нижнее меню для мобильных
- Возможность скрытия (`$hide_nav = true`)
- Адаптивные иконки

**`includes/header.php`**:
- Профиль пользователя справа вверху
- Dropdown меню с:
  - Мой профиль
  - Админ-панель (если админ)
  - Стать репетитором
  - Выйти
- Кнопка "Назад" (опциональная)
- Заголовок страницы

#### Главный шаблон:

**`includes/layout.php`** + **`includes/layout_footer.php`**

Пример использования:

```php
<?php
session_start();

$page_title = "Моя страница";
$page_css = ['custom.css']; // опционально
$page_js = ['custom.js']; // опционально
$compact = false; // true для компактного меню
$hide_nav = false; // true для скрытия нижнего меню
$show_back = false; // true для кнопки "Назад"

require_once 'includes/layout.php';
?>

<!-- Ваш контент здесь -->
<div>
    <h1>Привет!</h1>
</div>

<?php
require_once 'includes/layout_footer.php';
?>
```

Подробная документация: **`LAYOUT_USAGE.md`**

### ✅ 4. Страница ленты (feed.php)

Главная страница с персонализированной лентой постов.

#### Функции:

**Алгоритм рекомендаций:**
- ⭐ 40% - посты по интересам пользователя
- 🔥 30% - популярные посты (лайки/просмотры)
- ❤️ 20% - посты от избранных репетиторов
- 🆕 10% - новые посты

**Фильтрация:**
- ❌ Скрываются репетиторы оффлайн >24 часов
- ✅ Только активные и одобренные репетиторы

**Функционал:**
- Лайки с AJAX (без перезагрузки)
- Комментарии (подготовлено)
- Шаринг постов
- Отслеживание просмотров (Intersection Observer API)
- Пагинация

**Файлы:**
- `feed.php` - основная логика
- `style/feed.css` - стили ленты
- `js/feed.js` - интерактивность

### ✅ 5. Универсальный поиск (search.php)

Мощная система поиска по всей платформе.

#### Возможности:

**Типы поиска:**
- 👨‍🏫 Репетиторы
- 📝 Посты
- 📢 Каналы
- 🌐 Все вместе

**Фильтры для репетиторов:**
- Категория (языки, программирование, дизайн, и т.д.)
- Цена (мин/макс)
- Сортировка:
  - По релевантности
  - По рейтингу
  - По цене (возрастание/убывание)
  - Новые

**Особенности:**
- 🎯 **Smart Match** - умный подбор репетитора на основе:
  - Интересов пользователя
  - Бюджета
  - Истории взаимодействий
  - Активности репетитора
  - Рейтинга и опыта

**Логика отображения:**
- ⭐ Рейтинг показывается ТОЛЬКО если проведено >10 уроков
- ❌ Репетиторы оффлайн >24 часов не показываются
- 🟢 Индикатор "Онлайн" для активных репетиторов
- 👥 Количество учеников и уроков
- 💰 Цена за час

**Файлы:**
- `search.php` - логика поиска
- `style/search.css` - стили
- `js/search.js` - интерактивность

## 🚀 Как начать работу

### 1. Импорт базы данных

```bash
mysql -u root -p < database_aqum.sql
```

### 2. Обновление конфигурации

Проверьте `config.php`:
```php
define('DB_NAME', 'aqum_db');
```

### 3. Создание новых страниц

Используйте layout для всех страниц:

```php
<?php
session_start();
$page_title = "Моя страница";
require_once 'includes/layout.php';
?>

<!-- Контент -->

<?php require_once 'includes/layout_footer.php'; ?>
```

## 🔧 Технические детали

### Требования:
- PHP 7.4+
- MySQL 5.7+ / MariaDB 10.2+
- Apache/Nginx с mod_rewrite

### Зависимости:
- PDO для работы с БД
- Sessions для авторизации
- JSON для AJAX запросов

### Безопасность:
- Подготовленные запросы (защита от SQL-инъекций)
- Хеширование паролей (bcrypt)
- CSRF защита (в helpers.php)
- XSS защита (функция `e()`)

## 💡 Советы по использованию

### Создание новых страниц:

1. Скопируйте `includes/layout_example.php`
2. Настройте параметры ($page_title, $page_css, и т.д.)
3. Добавьте свой контент между layout.php и layout_footer.php
4. Готово! Меню появится автоматически

### Компактное меню (для чатов):

```php
$compact = true;
require_once 'includes/layout.php';
```

### Скрытие меню (для видеозвонков):

```php
$hide_nav = true;
require_once 'includes/layout.php';
```

### Кнопка "Назад":

```php
$show_back = true;
$back_url = '/previous-page.php';
require_once 'includes/layout.php';
```
