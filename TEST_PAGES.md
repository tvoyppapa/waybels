## 🔍 Проверка API:

### 1. Бронирование
```bash
# Создание записи
POST /api/create_booking.php
```
- [ ] Создается запись в базе
- [ ] Отправляется уведомление репетитору
- [ ] Возвращается booking_id

### 2. Получение уроков
```bash
# Получение уроков
GET /api/get_bookings.php
```
- [ ] Возвращает список уроков
- [ ] Только будущие и текущие
- [ ] Правильный формат JSON

### 3. Бот Wibs
```bash
# Отправка сообщения боту
POST /api/bot_wibs.php?action=send
```
- [ ] Сохраняет сообщение в базе
- [ ] Генерирует ответ бота
- [ ] Возвращает правильный JSON

## 🐛 Возможные ошибки:

1. **404 Not Found**
   - Проверьте что все файлы загружены
   - Проверьте права доступа

2. **500 Internal Server Error**
   - Проверьте логи PHP
   - Проверьте подключение к БД

3. **Пустая страница**
   - Проверьте синтаксис PHP
   - Включите отображение ошибок

4. **CSS не загружается**
   - Проверьте путь к `style/glass.css`
   - Очистите кэш браузера

5. **JavaScript не работает**
   - Откройте консоль браузера (F12)
   - Проверьте ошибки в консоли
