## 🧪 Тестирование

### 1. Тест Dashboard
1. Открой `http://chatax.online/dashboard.php`
2. Проверь glass эффект (должен быть полупрозрачным)
3. Нажми на ☀️ - тема изменится
4. Перезагрузи - тема сохранилась
5. Найди репетитора через поиск
6. Нажми ❤️ на карточке - добавится в избранное
7. Нажми "Подробнее"

### 2. Тест профиля репетитора
1. Открой `http://chatax.online/teacher.php?id=2`
2. Проверь большое фото
3. Проверь @username
4. Нажми 🔖 справа вверху - профиль сохранится
5. Нажми еще раз - профиль удалится из сохраненных
6. Нажми "Написать" - перейдет в чаты
7. Нажми "Записаться" - покажет alert (пока заглушка)

### 3. Тест темной темы
1. Нажми на ☀️ в dashboard
2. Все должно стать темным
3. Перейди на профиль репетитора
4. Он тоже должен быть темным
5. Перезагрузи - тема сохранилась
