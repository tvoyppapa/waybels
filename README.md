## 🛠 Установка

### 1. Требования
- PHP 7.4 или выше
- MySQL 5.7 или выше
- Apache/Nginx с mod_rewrite

### 2. Настройка базы данных

```bash
# Войдите в MySQL
mysql -u root -p

# Импортируйте схему
source /path/to/database.sql
```

Или через phpMyAdmin:
1. Создайте базу данных `wibs`
2. Импортируйте файл `database.sql`

### 3. Конфигурация

Отредактируйте файл `config.php`:

```php
// Настройки базы данных
define('DB_HOST', 'localhost');
define('DB_NAME', 'wibs');
define('DB_USER', 'root');
define('DB_PASS', 'your_password');
```

### 4. Права доступа

```bash
chmod 755 /workspace
chmod 644 /workspace/*.php
chmod 755 /workspace/style
chmod 755 /workspace/js
```

### 5. Запуск

Откройте в браузере:
```
http://localhost/index.php
```

## 📚 Использование

### Регистрация нового пользователя

1. Выберите интересующую категорию в квизе
2. Заполните форму регистрации
3. Система автоматически выполнит вход

### Вход в систему

1. Введите email и пароль
2. Нажмите "Войти"
3. При успешной аутентификации будет выполнен редирект на dashboard

### Выход

Перейдите на `/logout.php` или нажмите кнопку "Выйти" в dashboard

## 🔧 Настройка дополнительных функций

### Google OAuth

1. Зарегистрируйте приложение в [Google Cloud Console](https://console.cloud.google.com/)
2. Получите Client ID и Client Secret
3. Установите Google Client Library:
   ```bash
   composer require google/apiclient:"^2.0"
   ```
4. Раскомментируйте код в `google_login.php`
5. Добавьте учетные данные

### Восстановление пароля

1. Настройте отправку email (SMTP)
2. Раскомментируйте код в `reset_password.php`
3. Настройте параметры почты в `config.php`

## 📝 Валидация

### Правила валидации:

- **Email:** Стандартный формат email
- **Пароль:** Минимум 6 символов
- **Имя:** Минимум 2 символа

### Изменение правил:

Отредактируйте функции в `helpers.php`:
```php
function validatePassword(string $password): array {
    $errors = [];
    
    if (strlen($password) < 8) {
        $errors[] = "Пароль должен содержать минимум 8 символов";
    }
    
    if (!preg_match('/[A-Z]/', $password)) {
        $errors[] = "Пароль должен содержать заглавную букву";
    }
    
    // Добавьте свои правила
    
    return $errors;
}
```
