# ✅ Исправление ошибки "Table teacher_profiles doesn't exist"

## 🔍 Проблема

Dashboard выдавал ошибку HTTP 500:
```
Table 'wibs.teacher_profiles' doesn't exist
```

Код пытался сделать SELECT из несуществующей таблицы `teacher_profiles`.

## ✅ Решение

### 1. Создан SQL скрипт

**Файл:** `ADD_TEACHER_TABLES.sql`

Этот скрипт создает все необходимые таблицы:
- ✅ `teacher_profiles` - Профили репетиторов
- ✅ `posts` - Посты и материалы от репетиторов
- ✅ `favorites` - Избранные репетиторы
- ✅ `chats` - Чаты между пользователями
- ✅ `messages` - Сообщения в чатах
- ✅ `teacher_applications` - Заявки на репетиторство

### 2. Создан автоматический установщик

**Файл:** `apply_tables.php`

**📌 КАК ПРИМЕНИТЬ ИЗМЕНЕНИЯ:**

#### Вариант А: Через браузер (Самый простой!)

1. Откройте в браузере: `http://chatax.online/apply_tables.php`
2. Подождите, пока скрипт выполнится
3. Вы увидите отчет о созданных таблицах
4. Готово! 🎉

#### Вариант Б: Через phpMyAdmin

1. Откройте phpMyAdmin

5. Скопируйте весь SQL код

7. Нажмите "Выполнить"

### 3. Обновлены файлы

#### ✅ `index.php`
- Все ссылки теперь ведут на `auth_simple.php` (рабочая версия)

#### ✅ `auth.php` (НОВЫЙ!)

- Современный дизайн
