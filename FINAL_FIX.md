## Проблемы найдены:

### 1. ❌ Ошибка ini_set с сессией
```
Warning: ini_set(): Session ini settings cannot be changed when a session is active
```

**ИСПРАВЛЕНО** в `config.php`:
```php
// Теперь проверяем перед изменением настроек
if (session_status() === PHP_SESSION_NONE) {
    ini_set('session.cookie_httponly', 1);
    // ...
}
```

### 2. ❌ Авторизация не работает
Проблема в логике или редиректах.
