1. Откройте в браузере: `http://ваш-домен/setup_db_web.php`

3. Дождитесь завершения настройки
4. Проверьте результат через `check_db.php`

### Способ 2: Через командную строку MySQL

```bash
mysql -u root -p'WayBels2553030App!' < setup_database.sql
```

Или без пароля в команде (более безопасно):

```bash
mysql -u root -p < setup_database.sql
# Введите пароль: WayBels2553030App!
```

### Способ 3: Через phpMyAdmin

1. Откройте phpMyAdmin
2. Перейдите на вкладку "SQL"
3. Скопируйте содержимое файла `setup_database.sql`
4. Вставьте в окно SQL
5. Нажмите "Выполнить"

## 📊 Структура базы данных

### Таблица `users`
- Основная таблица пользователей
- Поддерживает роли: user, teacher, admin
- Хранит интересы, аватар, OAuth ID

### Таблица `teacher_profiles`
- Профили репетиторов
- Связь с `users` через `user_id`
- Содержит: предмет, описание, опыт, цену, рейтинг, видео

### Таблица `posts`
- Посты от репетиторов
- Может содержать изображения и видео
- Статистика лайков и просмотров

### Таблица `favorites`
- Избранные репетиторы для каждого ученика
- Уникальная связь user_id + teacher_id

### Таблица `chats`
- Чаты между двумя пользователями
- Хранит последнее сообщение

### Таблица `messages`
- Сообщения в чатах
- Статус прочтения

### Таблица `teacher_applications`
- Заявки на репетиторство
- Статусы: pending, approved, rejected

1. **Пароль БД** хранится в открытом виде в `db.php` — для продакшена используйте переменные окружения
2. **Тестовые данные** будут перезаписаны при повторном запуске скрипта
3. **Бэкап** — сделайте бэкап перед удалением БД, если там есть важные данные

## 🐛 Решение проблем

### Ошибка подключения
- Проверьте, запущен ли MySQL
- Проверьте правильность пароля в `db.php`
- Проверьте права пользователя root

### Таблицы не создаются
- Проверьте права пользователя MySQL на создание БД
- Проверьте логи MySQL на наличие ошибок
- Убедитесь, что используется правильная кодировка (utf8mb4)

### Ошибки при вставке данных
- Проверьте, что все внешние ключи правильно настроены
- Убедитесь, что пользователи создаются перед созданием профилей репетиторов
