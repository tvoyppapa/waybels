### 1. ✅ Убрано предупреждение при обновлении
**Проблема:** "На странице использовалась введенная информация..."  
**Решение:** Внедрен **PRG паттерн** (Post-Redirect-Get)
```php
// Ошибки хранятся в сессии
$_SESSION['error'] = 'Текст ошибки';
header('Location: auth.php');
exit;

// На странице читаем и очищаем
$error = $_SESSION['error'] ?? '';
unset($_SESSION['error']);
```

## 🔧 КАК РАБОТАЕТ PRG ПАТТЕРН

### Старая версия (НЕ РАБОТАЛА):
```php
if ($_POST) {
    // обработка
    $error = 'Ошибка';
}
// показываем HTML с ошибкой
```
**Проблема:** При F5 браузер спрашивает "повторить отправку формы?"

### Новая версия (РАБОТАЕТ):
```php
if ($_POST) {
    // обработка
    $_SESSION['error'] = 'Ошибка';
    header('Location: auth.php');  // ← редирект
    exit;
}

// GET запрос - читаем из сессии
$error = $_SESSION['error'] ?? '';
unset($_SESSION['error']);  // ← очищаем
```
**Результат:** При F5 просто обновляется GET запрос, нет предупреждения!

## 📝 УНИКАЛЬНЫЕ NAME ДЛЯ КНОПОК

### Проблема:
```html
<button name="login">Войти</button>         ← форма 1
<button name="register">Регистрация</button> ← форма 2
```
Браузер мог отправить не ту форму!

### Решение:
```html
<button name="login_submit">Войти</button>
<button name="register_step1">Шаг 1</button>
<button name="register_step2">Шаг 2</button>
<button name="register_step3">Шаг 3</button>
```

В PHP:
```php
if (isset($_POST['login_submit'])) { ... }
elseif (isset($_POST['register_step1'])) { ... }
elseif (isset($_POST['register_step2'])) { ... }
elseif (isset($_POST['register_step3'])) { ... }
```
