# 🔧 Инструкция по настройке базы данных

## Проблема
База данных `wibs` не содержит таблицу `teacher_profiles` и другие необходимые таблицы для функционала репетиторов.

## Решение

### Вариант 1: Через браузер (Рекомендуется)

1. Откройте в браузере: `http://chatax.online/apply_tables.php`
2. Скрипт автоматически создаст все необходимые таблицы
3. После завершения проверьте результат на экране

### Вариант 2: Через phpMyAdmin

1. Откройте phpMyAdmin
2. Выберите базу данных `wibs`
3. Перейдите на вкладку "SQL"
4. Скопируйте содержимое файла `ADD_TEACHER_TABLES.sql`
5. Вставьте в окно SQL и нажмите "Выполнить"

### Вариант 3: Через командную строку (если доступен mysql)

```bash
mysql -u root -p'WayBels2553030App!' wibs < ADD_TEACHER_TABLES.sql
```

## Что будет создано

1. **teacher_profiles** - Профили репетиторов
2. **posts** - Посты и материалы от репетиторов
3. **favorites** - Избранные репетиторы
4. **chats** - Чаты между пользователями
5. **messages** - Сообщения в чатах
6. **teacher_applications** - Заявки на репетиторство

## Тестовые данные

Скрипт также добавит:
- 5 тестовых репетиторов
- 4 тестовых поста
- Тестовые данные для демонстрации

## После применения

1. Откройте `http://chatax.online/auth_simple.php`
2. Войдите или зарегистрируйтесь
3. Перейдите на `http://chatax.online/dashboard.php`
4. Вы должны увидеть список репетиторов

## Проверка

Чтобы проверить, что таблицы созданы:
```sql
SHOW TABLES LIKE '%teacher%';
SELECT COUNT(*) FROM teacher_profiles;
```
