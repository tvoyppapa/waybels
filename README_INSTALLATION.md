## ❓ ПРОБЛЕМЫ?

### Не устанавливается БД?
1. Проверьте, что MySQL запущен
2. Проверьте пароль в `db.php` (должен быть `WayBels2553030App!`)

### Не работает вход?
1. Откройте `clear_session.php` для очистки сессии
2. Попробуйте снова

### Не перебрасывает на feed.php?
1. Проверьте, что в `config.php` указано: `define('DASHBOARD_URL', 'feed.php');`
2. Проверьте, что в `db.php` указано: `$dbname = "aqum_db";`
