## ❗ Если что-то не работает:

### Проблема: "404 Not Found"
**Решение:** Проверьте что файл существует и права доступа правильные

### Проблема: "500 Server Error"
**Решение:** Проверьте логи PHP (`tail -f /var/log/php-errors.log`)

### Проблема: Страница пустая
**Решение:** Включите отображение ошибок в `php.ini`

### Проблема: CSS не загружается
**Решение:** Очистите кэш браузера (Ctrl+Shift+R)

### Проблема: База данных
**Решение:** Проверьте что все таблицы созданы:
```sql
SHOW TABLES;
```
