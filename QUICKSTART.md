# 🚀 Быстрый старт Wibs

## Минимальная настройка за 5 минут

### Шаг 1: База данных

```bash
# Войдите в MySQL
mysql -u root -p

# Создайте БД и импортируйте схему
CREATE DATABASE wibs CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE wibs;
source /path/to/workspace/database.sql;
```

### Шаг 2: Конфигурация

Откройте `config.php` и измените настройки БД:

```php
define('DB_HOST', 'localhost');      // Хост БД
define('DB_NAME', 'wibs');           // Имя БД
define('DB_USER', 'root');           // Пользователь
define('DB_PASS', 'your_password');  // Пароль
```

### Шаг 3: Права доступа

```bash
cd /workspace
chmod 755 .
chmod 644 *.php
```

### Шаг 4: Запуск

**Локальный сервер PHP:**
```bash
php -S localhost:8000
```

Откройте: `http://localhost:8000/index.php`

**Или настройте Apache/Nginx:**
- Укажите DocumentRoot на `/workspace`
- Откройте в браузере

### Шаг 5: Тестирование

Войдите с тестовыми данными:

| Email | Пароль |
|-------|--------|
| test@example.com | password |

## 🔧 Настройка для продакшена

### 1. Безопасность

В `config.php`:
```php
// ОТКЛЮЧИТЕ отображение ошибок
error_reporting(0);
ini_set('display_errors', 0);

// Включите HTTPS
ini_set('session.cookie_secure', 1);
```

### 2. База данных

```sql
-- Создайте пользователя с ограниченными правами
CREATE USER 'wibs_user'@'localhost' IDENTIFIED BY 'strong_password';
GRANT SELECT, INSERT, UPDATE, DELETE ON wibs.* TO 'wibs_user'@'localhost';
FLUSH PRIVILEGES;
```

### 3. .htaccess

Раскомментируйте в `.htaccess`:
```apache
# Редирект на HTTPS
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

### 4. Логирование

Создайте файл `/var/log/wibs/error.log` и настройте:
```php
error_log($error, 3, '/var/log/wibs/error.log');
```

## 🐛 Решение проблем

### Ошибка подключения к БД
```
Проверьте:
1. MySQL запущен
2. Настройки в config.php правильные
3. База данных создана
4. Пользователь имеет права доступа
```

### Не работают сессии
```
Проверьте:
1. Права на /tmp или session.save_path
2. session_start() вызывается
3. Нет вывода до session_start()
```

### CSS/JS не загружаются
```
Проверьте:
1. Пути к файлам правильные
2. Файлы существуют
3. Права на чтение файлов (644)
4. .htaccess настроен
```

### Формы не отправляются
```
Проверьте:
1. Консоль браузера (F12)
2. Логи PHP ошибок
3. CSRF токен присутствует
4. POST данные приходят
```
